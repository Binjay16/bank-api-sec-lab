# bank-api-sec-lab

A small bank-style JSON API built in Rails, **deliberately seeded with security flaws**, then
scanned with [Brakeman](https://brakemanscanner.org/), documented, and fixed.

> ⚠️ **Do not deploy the `v0-vulnerable` tag.** It exists to be attacked and fixed in a lab.
> All credentials in `db/seeds.rb` are throwaway demo values.

Work in progress: see git history.
